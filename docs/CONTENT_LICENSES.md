# Content Licenses

## King James Version (KJV)

The Bible platform currently uses the 1769 KJV verse dataset supplied by the `kjv` npm package.

- Source repository: `farskipper/kjv`
- Dataset: `json/verses-1769.json`
- Dataset statement: Public Domain
- Package license: MIT
- Package version pinned in this project: `1.0.0`

The source repository states that the KJV JSON dataset is public domain and that the package itself is MIT licensed. The platform keeps the source and licensing decision documented here so a future translation can be added only after its rights are reviewed.

### Production caution

Public-domain status can vary by jurisdiction, especially for historical editions and formatting. Before commercial/global launch, review the applicable jurisdictions and retain provenance for the exact dataset version used by the application.

`data/bible/sample-kjv.json` remains in the repository as a small development fixture. It is no longer the production Bible source.
